The MIT License covers software and documentation files where no more specific

build, fork, service, or distribution is an official Palot release or is
endorsed by the Palot project.

If you publish a fork or modified distribution:

- use a distinct product name and app identity;
- do not use Palot logos or icons in a way that implies an official release or
  endorsement;
- state clearly that the project is independently maintained;
- preserve license and provenance notices required by the files you reuse.

You may use the Palot name to describe compatibility, origin, or factual
relationship, for example "a fork of Palot," as long as the wording is not
misleading.
