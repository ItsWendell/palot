# Support

Palot is pre-release software built from source. There is no paid support,
service-level agreement, or supported public binary channel.

## Where to ask

- [GitHub Discussions](https://github.com/ItsWendell/palot/discussions) are
  the planned home for setup questions, ideas, and general help, but they are
  currently disabled.
- Use [GitHub Issues](https://github.com/ItsWendell/palot/issues) for
  reproducible Palot bugs, scoped feature requests, and current support
  questions.
- Use the in-app About page for direct links to documentation, issues, security,
  privacy, licenses, release notes, and the current GitHub release page.
- Use a private
  [GitHub Security Advisory](https://github.com/ItsWendell/palot/security/advisories/new)
  for vulnerabilities or sensitive data exposure.

OpenCode installation, provider behavior, account access, model output,
plugins, MCP servers, and OpenCode service bugs may belong in the relevant
upstream project rather than Palot.

## Bug reports

Include:

- the Palot commit or version;
- OpenCode version, currently required to be `0.0.0-beta-19234`;
- macOS version and CPU architecture;
- exact reproduction steps and expected behavior;
- the smallest useful log or diagnostic excerpt;
- screenshots or recordings when the problem is visual.

Remove credentials, prompts, private source, repository paths, tokens, server
authorization headers, and unrelated logs. Do not upload a complete trace or
support artifact without reviewing it first.

Unsigned local packages can trigger macOS security warnings. Public Developer ID
signed and Apple-notarized packages are not available.
